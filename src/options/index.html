头歌学习助手

题面抽取 · 代码生成 · 自动写入编辑器 · 自动点评测并回灌重试。设置只在扩展页面内修改。

模型

换到列表以外的网关时，点"保存 / 测试连接"会弹出域名授权——不允许的话请求只会返回 Failed to fetch。

密钥只保存在扩展的 chrome.storage.local 中，且已收紧为仅可信上下文可读；页面脚本与内容脚本都拿不到明文。 自动评测会消耗课程评测次数：次数紧张的课程把"失败重试次数"调到 0，或先关掉自动提交。

本地答案库

通过评测的代码按题目指纹存在本机 storage.local，容量上限 200 条，只在本机使用、不上传。 题目正文或代码模板一改，指纹就变，旧记录自动失效；超过 30 天未使用的记录也会被丢弃。

使用

  1. 打开头歌实训题页面（…/classrooms/…/shixun_homework/…）。
  2. 右上角出现"头歌学习助手"面板，题面会自动读取；没有出现时点面板上的"重新抽取"。
  3. 点"自动解题"：生成代码 → 写入编辑器 → 回读校验 → 点评测 → 读结论，失败自动回灌重试。
  4. 点"讲解思路"看分步提示；点"复盘代码"让模型检查你在编辑器里写的代码。
